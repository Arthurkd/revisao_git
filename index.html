💻 Atalhos do Visual Studio Code

Edição

Copiar linha Shift + Alt + ↑/↓
Mover linha para cima/baixo Alt + ↑/↓
Duplicar seleção/linha Shift + Alt + ↑/↓
Excluir linha Ctrl + Shift + K
Comentar/descomentar linha Ctrl + /
Comentar bloco Shift + Alt + A
Formatar documento Shift + Alt + F
Formatar seleção Ctrl + K → Ctrl + F

Navegação

Paleta de comandos Ctrl + Shift + P
Abrir arquivo Ctrl + P
Pesquisar no arquivo Ctrl + F
Substituir Ctrl + H
Pesquisar no projeto Ctrl + Shift + F
Ir para linha Ctrl + G
Ir para símbolo Ctrl + Shift + O
Voltar Alt + ←
Avançar Alt + →

Terminal e arquivos

Novo terminal Ctrl + Shift + `
Mostrar/ocultar terminal Ctrl + `
Novo arquivo Ctrl + N
Abrir arquivo Ctrl + O
Salvar Ctrl + S
Salvar tudo Ctrl + K → S
Fechar editor Ctrl + W

Multi-cursor e seleção

Adicionar cursor acima/abaixo Ctrl + Alt + ↑/↓
Selecionar próxima ocorrência Ctrl + D
Selecionar todas as ocorrências Ctrl + Shift + L
Desfazer seleção Ctrl + U

Depuração

Iniciar / continuar debug F5
Executar sem debug Ctrl + F5
Breakpoint F9
Step Over F10
Step Into F11
Step Out Shift + F11
💡 Dica: pressione Ctrl + Shift + P para abrir a Paleta de Comandos e descobrir praticamente qualquer função disponível no VS Code.

🌿 Principais comandos do Git

Configuração

git config --global user.name "Nome" Define seu nome
git config --global user.email "email" Define seu e-mail
git config --list Lista configurações

Repositório

git init Cria um novo repositório Git
git clone URL Clona um repositório remoto
git status Mostra o estado atual

Alterações

git add arquivo Adiciona um arquivo ao stage
git add . Adiciona todas as alterações
git commit -m "mensagem" Cria um commit
git diff Mostra alterações não adicionadas
git diff --staged Mostra alterações no stage

Branches

git branch Lista branches
git branch nome Cria uma branch
git switch nome Troca de branch
git switch -c nome Cria e troca para uma branch
git merge nome Mescla uma branch
git branch -d nome Exclui uma branch local

Repositório remoto

git remote -v Lista repositórios remotos
git remote add origin URL Adiciona um remoto
git push Envia commits para o remoto
git push -u origin main Publica a branch pela primeira vez
git pull Baixa e integra alterações
git fetch Baixa alterações sem fazer merge

Histórico

git log Exibe o histórico
git log --oneline Histórico resumido
git show Mostra detalhes de um commit
git blame arquivo Mostra autoria por linha

Desfazer alterações

git restore arquivo Descarta alterações locais
git restore --staged arquivo Remove arquivo do stage
git revert HASH Cria um commit que desfaz outro
git reset --soft HEAD~1 Desfaz o último commit mantendo alterações

🚀 Fluxo de trabalho mais comum

# 1. Verificar alterações
git status

# 2. Adicionar arquivos
git add .

# 3. Criar commit
git commit -m "Descrição da alteração"

# 4. Atualizar branch local
git pull

# 5. Enviar para o GitHub/GitLab/etc.
git push
